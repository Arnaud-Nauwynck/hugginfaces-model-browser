
This project is for analyzing open-source projects, 
scrapping source information from Jira + Github + MailingList,
enriching with user-defined annotated data,
persisting as local compressed files on he local disk,
and re-exposing all data with java springboot Rest json endpoints for the corresponding Angular SPA ui, and also exposing as MCP server.

# Backend

source in src/main/java/**.java
very standard maven + java + springboot + lombok + OpenApi + MCP   technology stack.

Code style follow Oracle style.
Also follow SOLID architecture principle : S=Single (most important), O=Open-Close, L=Liskov, I=Interface segregation (not important when using a single springboot @Service class implementation), D=Dependency)
every class should do only 1 thing, and delegate to others if too complex.

There are almost NO unit tests yet, and it is ok. No need to launch any test. Then end-user will do himself.

After each edition of source code, the end-user will follow and recompile (in IntelliJ / maven) himself, almost in real-time.
The end user will say as soon as there is a compile error, so do not waste tokens trying to launch mvn and analyze results output.

Never try to inspect maven jar dependencies, ask and the end-user will provide.

# Frontend

source in src/main/webapp
very standard Angular (typescript) + ag-grid + ... technology stack.

Angular component classes used as page, in 'app.route.ts', should be suffixed with 'Page'. 

After each edition of source code, the end-user will follow and recompile (in "ng serve") himself in real-time.
The end user will say as soon as there is a compile error, so do not waste tokens trying to launch "ng" and analyze results output.

All rest api classes for service and interfaces for DTO are generated by end-user himself to strictly map java<->typescript type-checking.
Do NOT modify any file under src/main/webapp/src/app/rest/**, as it is fully generated. 

Never try to inspect node/npm module dependencies, ask and the end-user will provide.

# Git

After each edition of source code, the end-user will commit himself in git, so do not waste tokens trying to do it or even to display suggestion message.
